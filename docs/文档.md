# EGOEquipment 装备模组

~110 武器 + ~30 护甲套装。

## 武器分类

近战：AXE / FIST / HAMMER / KNIFE / MACE / SPEAR / SWORDS + 27 特殊
远程：CANNON / PISTOL / RIFLE / CROSSBOW + 7 特殊

基类层次：`EgoWeaponItem → MeleeEgoWeaponItem / RemoteEgoWeaponItem → 具体子类`

## 注册模式

```kotlin
val WINGBEAT = onMelee<MeleeEgoWeaponItem>()
    .id("wingbeat_weapon").zhName("翅振")
    .lcLevelType(LcLevel.ZAYIN).type(MeleeTemplateType.SWORDS)
    .properties { it.damage(6f).meleeLcDamageType(LcDamageType.PHYSICS) }
    .model(EGOEquipment.modRl("weapon/wingbeat"))
    .buildAndRegister()
```

## 护甲

5 风险等级材料（zayin/teth/he/waw/aleph），三件套，四色伤害减免系数。
